# Maple Bridge Portfolio

CPT208 Human-Centric Computing — Group A2-4

This repository contains the process portfolio for our CPT208 project focused on redesigning the cultural tourism experience at Maple Bridge (Fengqiao), Suzhou.

The portfolio is presented as a GitHub Pages website to document the full design process, from early research and requirement gathering to concept development, prototyping, evaluation, and reflection.

Main areas included in the portfolio:
- overview of the problem
- research findings and personas
- journey mapping and insights
- concept evolution
- final design direction
- reflection, evaluation, and references
